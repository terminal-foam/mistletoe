# 流明·星 M1 实现说明

日期：2026-11-11。基于 `9eedc62`（main，v0.1.2 之后）。

## 本次范围（M1）

只做“能召唤、能打、有血条、能换阶段”的底座，不做招式与终局蓄力。

| 内容 | 实现 |
|---|---|
| 实体注册 | `mistletoe:lumen_seishin`，`MobCategory.MONSTER`，碰撞箱 0.6×1.8 |
| 属性 | 360 HP / 护甲 12 / 韧性 4 / 移速 0.30 / 击退抗性 0.5 / 索敌 24 |
| 血条 | `ServerBossEvent`，按阶段换色：朝露蓝、初雪白、暮色紫 |
| 阶段 | 生命 >240 朝露、120<生命≤240 初雪、≤120 暮色；只前进不回退 |
| 阶段锁血 | `LivingIncomingDamageEvent` 把跨阈值的伤害截到阈值；换阶段后有 20 tick 无敌 |
| 换刀 | 每个阶段把主手换成对应 named blade（朝露 / 初雪 / 暮色），OBJ 正常渲染 |
| 存读档 | 阶段与锁血 tick 写入 NBT |
| 召唤 | `/mistletoe boss` + 刷怪蛋 |
| 渲染 | 占位：`PlayerModel` + 原版 steve 皮肤，手里由 `ItemInHandLayer` 渲染刀 |
| 战利品 | 占位：`minecraft:echo_shard` ×4 |

## 与玩家版的分工

- **外观拿刀**，但 Boss 的伤害**不走**玩家的 `attack_base` 连段公式，也不走 `MistletoeCombat` 的霜刃/斩星结算。
- 文档中的 10% / 25% 是 **Boss → 玩家** 的伤害，在后续里程碑单独实现。
- 实体属性表里加了 `SWEEPING_DAMAGE_RATIO = 0`：SlashBlade 的 `AttackHelper.getSweepingBonus` 会无条件读它，非玩家缺这个属性会在出刀光时抛异常。
