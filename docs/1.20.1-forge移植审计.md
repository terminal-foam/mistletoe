## 已知阻塞点

### 1. 加载器与构建

- NeoForge → **Forge 47**
- `neoforge.mods.toml` → **`META-INF/mods.toml`**
- `@Mod`、`IEventBus`、`ModContainer` 的构造方式需要按 Forge 1.20.1 改
- `DeferredHolder` → **`RegistryObject`**
- `ModConfigSpec` → **`ForgeConfigSpec`**
- `NeoForge.EVENT_BUS` → **`MinecraftForge.EVENT_BUS`**
- `@EventBusSubscriber` → **`@Mod.EventBusSubscriber`**
- `pack.mcmeta` 改为 1.20.1 的 **pack_format 15**
- 需要 ForgeGradle 6 / Forge 47 MDK 或等价的离线编译基座

### 2. 伤害事件

- `LivingIncomingDamageEvent`（1.21.1 NeoForge）→ Forge 1.20.1 的
  **`LivingHurtEvent` / `LivingDamageEvent`**
- 平 A 公式、同一 attacker:target 每 tick 只套一次的去重、Super 的绝对伤害、
  Boss cap 绕过标签都要在 1.20.1 重新验证
- Cataclysm 3.09 的 `damage_cap` / `dps_cap` 行为要单独测

### 3. SlashBlade 2.1.9 → 1.1.23

这是最大风险项，不能假设 API 兼容：

- `SlashArts` 注册
- `ComboState` / `ModComboStates`
- `ISlashBladeState` / `BladeStateAccess`
- `InputCommandEvent` / SPRINT 长按输入
- `SuperSlashArts` / `EntitySlashEffect` / `AttackManager`
- `SlashBladeTEISR` 的物品图标渲染
- 1.1.23 的 Super 触发条件、SA 冷却、耐久顺序

### 4. 数据与资源

- `data/minecraft/tags/damage_type` 的 1.20.1 标签
- `data/minecraft/tags/entity_type`（1.20.1 的实体标签目录）
- `data/mistletoe/damage_type`、`slashblade/named_blades`、配方、成就
- 1.20.1 的 `pack.mcmeta` 与资源路径
- `mistletoe.mixins.json` 的 refmap / Mixin 0.8.5 配置

### 5. 测试

- Forge 1.20.1 的 GameTest（`@GameTestHolder` / `GameTestHelper`）
- JUnit 纯公式测试可直接复用
- 专服加载测试
- Closing Song 的 286 个 mod 环境（Cataclysm、Apotheosis 等）实测

## 可以复用的部分

- `MistletoeFormulas` 纯数学
- v0.2.1 的 OBJ/PNG、named blade JSON 结构
- 伤害类型、SA 命名、配置项语义
- 现有文档和测试思路

## 分阶段

1. **构建骨架**：Forge 47 + Java 17 能编译一个空 `@Mod`，`mods.toml` 能加载。
2. **注册/资源**：物品、声音、粒子、SA/Combo 注册，named blade 能出现在创造栏。
3. **普通攻击/SA**：Forge 伤害事件 + 1.1.23 API，先让平 A 和斩星跑通。
4. **Super/阶段锁**：Super 输入、绝对伤害、Boss cap 绕过、阶段锁适配。
5. **GameTest/JUnit/专服**：18 个测试重新落地。
6. **Closing Song 集成**：286 mod 环境，Cataclysm 实测。
