# 美术模型 v0.2.1

来源：

- 暮色：`terminalblade_mistletoe_art_v0.2.1.zip` 的 `dist/`，偏白/浅绿默认色调。
- 朝露：`terminalblade_mistletoe_art_v0.2.1_deepgreen.zip` 的 `dist/`，深绿刀鞘版本。

两把刀使用同一个 4650 面网格，只有图集色调不同。

## 模型

- 13 组，13950 顶点、4650 面，1,039,792 字节。
- 1024×1024 RGBA 图集：暮色 309,551 字节（偏白）；朝露 309,184 字节（deepgreen）。
- `check_ingame.py`：**PASS**，0 项失败。
- `item_blade` / `item_bladens`：112 面，跨度 150.3，`z[1.2,4.8]`，+Z 面 100%。
- `sheath`：1440 面朝外，0 朝内；`blade` 33% 朝内。

## v0.2.1 的关键变化

v0.2.1 修正了 v0.2.0 的形状方向：

- **反り（sori）改为向下**，与 `terminalblade-0.1.3.jar` 的参考方向一致；
- 刀身带脊线（ridged blade）；
- 刀鞘改为**钝头（blunt kojiri）**，并跟着反り向下；
- 装饰层和贴图保持不变。

`shape_compare.png` 三行：JAR013 参考 / v0.1.9 旧版 / v0.2.1 融合版。v0.1.9 是扁片刀身 + 跟刀尖收窄的鞘；v0.2.1 是向下反り + 脊线 + 钝头鞘。
