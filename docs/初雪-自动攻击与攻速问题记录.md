# 初雪：自动攻击与攻速问题记录

更新日期：2026-11-09。适用范围：Minecraft 1.21.1 / NeoForge 主工程。

## 1. 结论先行

当前自动攻击/攻速实现建立在**错误的输入语义**上，不能作为最终方案。

SlashBlade Resharped 的实际输入：

```text
右键点按          -> 普通攻击（平A）
右键长按后松开    -> SA
```

不是左键。

之前的实现一直使用：

```java
client.options.keyAttack   // 左键
```

并进一步做成了服务端左键循环。  
这条路径不是 SlashBlade 的普通攻击路径，因此：

- 左键自动攻击的命中日志不能代表右键平A速度
- 服务端直接 `target.hurt` 会绕开普通攻击的连段、蓄力、耐久和 SA 语义
- 自动短按右键又会打断“长按松开SA”

在输入语义解决之前，不应继续堆攻击频率补丁。

## 3. 实测数据

### 3.1 攻速属性

- 早期 `ItemAttributeModifierEvent` 只让物品 modifier 生效，玩家属性仍是 **4.0**
- 改为 `FirstSnowSpeedHandler` 玩家 tick 维护后，`/attribute @s minecraft:generic.attack_speed get` 显示 **40.0**

### 3.2 左键自动攻击（错误输入路径）

不同阶段日志：

```text
初雪：中位间隔约 200ms，约 3 次/秒
朝露：中位间隔约 200ms，约 4 次/秒
```

说明左键自动攻击并没有让初雪比朝露快。  
中间的 50ms 连续段是同一刀/额外伤害/其它伤害，不是两次普通攻击。

改成服务端直伤后，日志出现：

```text
初雪：129 次命中，中位间隔 52ms
```

但这是**服务端直接 `hurt`** 的结果，不是右键平A，不能作为最终验收。

### 3.3 受击无敌帧

多次尝试：

1. `LivingDamageEvent.Post` 清 `invulnerableTime`
2. 下一 tick 清
3. `LivingEntity.hurt` RETURN Mixin 清
4. `LivingIncomingDamageEvent` 登记目标 + 每 tick 清

都没有稳定把实际平A频率拉到目标值。  
Warden / Legendary Monsters 等目标还有自己的 `hurt`/减伤/高血量，不能用它们单独验证普通攻速。

## 4. 当前真正的问题

### F-01 输入语义错误

自动攻击使用左键，而 SlashBlade 普通攻击是右键点按。  
这是最高优先级问题，必须先修，否则攻速数据全部失真。

### F-02 右键点按与长按SA冲突

同一右键：

```text
短按 -> 平A
长按 -> SA
```

自动短按会不断释放右键，导致无法长按蓄力 SA。

### F-03 服务端直伤绕开普通攻击

`FirstSnowHoldScheduler` 直接调用：

```java
target.hurt(player.damageSources().playerAttack(player), damage)
```

不会经过：

- SlashBlade 的右键 `use` / `releaseUsing`
- 普通连段推进
- 蓄力/Just 窗口
- 耐久与 SA 语义

### F-04 目标侧限制

- Warden / LM 实体有自定义 `hurt`、减伤、高血量
- 受击无敌帧和伤害上限会吞掉高频攻击
- 用这些目标测“攻速”容易得出错误结论

## 5. 可选方案

### 方案 A：自动右键点按平A

按住右键时自动短按，按 `ATTACK_SPEED` 间隔触发普通攻击。  
优点：符合右键平A语义。  
缺点：会打断长按蓄力 SA，SA 基本不可用。

### 方案 B：保留右键SA，平A自动用其他触发

右键长按松开仍是 SA；平A由左键/服务端循环/独立键负责。  
优点：SA 保留。  
缺点：偏离原版操作，需要明确告知玩家。

### 方案 C：不自动，只调整右键平A冷却和动画

保留手动右键点按；只改 `ATTACK_SPEED`、`ComboState.speed`、A1–A5 快速副本。  
优点：输入语义正确，不会破坏 SA。  
缺点：人手点击频率仍是上限。

### 方案 D：混合

客户端检测右键按住时长：

- 短按/未超过阈值：自动重复平A
- 超过 SA 阈值：停止自动，让 SA 蓄力
- 松开：释放 SA

优点：接近理想。  
缺点：阈值、释放窗口和误触处理复杂，需要实机反复调。

## 6. 建议

1. 先撤掉左键自动攻击和左键服务端直伤，避免继续产生错误数据。
2. 明确选择方案 A/B/C/D。
3. 如果选 C，保留：
   - `FirstSnowSpeedHandler` 的 +36 攻速
   - `FastComboBridge` 地面 A1–A5
   - `FROST_BLADE` 2.4x / 2 tick
4. 如果选 A/D，需要重做输入层，不能复用当前左键 payload。
