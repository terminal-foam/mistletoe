## 这次同步了什么

1.20.1 端口原来停在 0.1.2 早期基线（只有暮色、旧配方、旧占位音效）。本次已同步到 1.21.1 当前功能：

- 新增朝露 `mistletoe:dawn`：named blade、深绿模型、`mistletoe:xiwei` SA、合成刀铭。
- 旧暮色配方改为产出朝露；新增“四末影水晶 + 二魂灵晶 + 二下界之星 + 妖刀朝露”的暮色配方。
- 暮色鞘上的 Super 蓄力藤蔓：`growth_white` 模型 + `MistletoeGrowthRenderer`。
- 音效只保留 `sacrifice` / `super_charge`，删除旧占位音；Super 蓄力沿用服务端 5 tick 后的 `super_charge`。
- 创造/旁观玩家不再支付普通 SA 与 Super SA 的生命献祭。
- 朝露不套暮色的生命差公式，Super 入口也拒绝朝露。

## 1.20.1 渲染适配

1.20.1 的 SlashBlade 1.1.23 与 2.1.9 渲染 API 不同：

- `RenderOverrideEvent` 没有 `getGetRenderType()` / `getPackedLightIn()`。
- `WavefrontObject.tessellateOnly` 只有 `(VertexConsumer, String...)`，不接收 PoseStack / light / color。

适配方式：

- 用 `BladeRenderState.getSlashBladeBlend` / `getSlashBladeBlendLuminous` 取 RenderType。
- 绘制前设置 `Face.setMatrix(pose)`、`Face.setLightMap(LightTexture.FULL_BRIGHT)`、`Face.setCol(Color.WHITE)`。
- 事件返回后 `BladeRenderState` 会重新设置并 reset，不需要额外恢复。

模型解析验证：用 1.1.23 的 `WavefrontObject` 直接读取 `mistletoe.obj`，得到 **77 个组**，其中 `grow_lum` 32 个，藤蔓组齐全。
