## 关键适配

- `@Mod` 改为 Forge 无参构造
- `ForgeConfigSpec` / `ForgeConfigSpec.Builder`
- `MinecraftForge.EVENT_BUS`
- `RegistryObject` / `Forge` `DeferredRegister`
- `LivingHurtEvent` 替代 `LivingIncomingDamageEvent`
- `ServerTickEvent` + `Phase.END`
- `ItemSlashBlade.BLADESTATE` capability 替代 `BladeStateAccess`
- `SlashArtsRegistry` / `ComboStateRegistry`
- `InputCommandEvent` 包路径改为 `event.InputCommandEvent`
- 1.20.1 数据目录：`recipes` / `advancements` / `entity_types`
- 1.20.1 配方：`result.item`、`items` 数组
- MixinGradle + refmap；`EntitySlashEffectMixin.tick -> m_8119_`
- `SuperSlashArtsMixin.releaseSSA` 使用 `remap = false`，因为 1.1.23 该 mod 方法名未混淆
- `mods.toml` 使用 `mandatory=true`
