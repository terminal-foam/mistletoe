# 美术模型 v0.2.0

来源：`terminalblade_mistletoe_art_v0.2.0.zip` 的 `dist/`。

## 模型

- 13 组，13470 顶点、4490 面，997,423 字节。
- 1024×1024 RGBA 图集，309,551 字节（与 v0.1.9 相同，本次只改形状）。
- `check_ingame.py`：**PASS**，0 项失败。
- `item_blade` / `item_bladens`：112 面，跨度 150.3，`z[1.2,4.8]`，+Z 面 100%。
- `sheath`：1280 面朝外，0 朝内；`blade` 33% 朝内（v0.1.9 是 35%）。

## v0.2.0 的关键变化

v0.2.0 是**形状融合版**：

- 用 `terminalblade-0.1.3.jar` 的刀身剪影作为参考；
- 保留 v0.1.9 的装饰层、贴图、徽记；
- 刀身改成 **Sori 18** 的弧度、带脊线；
- 刀鞘改成等宽（constant saya），不再跟着刀尖收窄。

`shape_compare.png` 里三行分别是：JAR013 参考、v0.1.9 旧扁片、v0.2.0 融合版。装饰层在 v0.1.9 和 v0.2.0 之间是逐字节一致的。
