# 测试与已知限制

版本 0.1.2。JUnit、GameTest、专用服务器加载和客户端手动验收是四类不同证据，不能互相代替。

## 命令

Gradle 环境：

```bash
./gradlew test
./gradlew runGameTestServer
```

本机没有 Gradle 缓存时：

```powershell
.\build-1.21.1.ps1 -Clean -Verify
.\run-tests.ps1
```

`test` / `run-tests.ps1` 只跑 JUnit。`runGameTestServer` 才跑游戏内 GameTest。GameTest 类在 `gametest` 包，生产 jar 已排除，避免测试用事件监听器随包发布。

## 已知限制

- 强制处决只能对付“正常死亡事件被取消”这一层；目标模组如果每 tick 回血、替换实体、自定义复活，仍然可能挡住，需要专项适配。不得声称兼容所有模组 Boss。
- 阶段锁血只有动态适配器和静态保护标签两种来源；未适配 Boss 默认按普通实体处理，静态标签是保守兜底，不是自动识别。
- 普通 SA 绕过本体 `TargetSelector`：不检测墙体、没有独立 PvP/队友规则；本体 `pvp_enable` / `friendly_enable` 和实体黑名单也拦不住普通 SA。
- 普通攻击/普通 SA 的伤害由公式决定，本体的 `attack_base`、精炼、锋利、力量、暴击倍率不参与；护甲、抗性、附魔减伤仍生效。
- `superAffectTamed=true` 时影响所有玩家的宠物，不是只影响施法者的（D-05）。
- 耐久消耗受 Unbreaking 影响（D-09）；本刀默认 Unbreaking 3，`maxDamage/2` 的名义值会被减伤。
- 占位音效是合成单音，占位模型是低模打刀；`effect` 组也是占位光壳，不是最终造型。
- 动作仍复用本体 `combostate/motion.vmd` 的帧段；正式 VMD 在 0.2.0。
- 专属 SE 未做。
