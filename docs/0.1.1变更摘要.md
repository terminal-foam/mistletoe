# 0.1.1 变更摘要

基准是 0.1.0。这轮不改 D0、k、100 HP 阈值、10% 当前生命、20% 最大生命和 90% Super 献祭。D-01 到 D-08 没有新结论，行为保持原样，并在 `docs/技术决策.md` 里标成待确认。

这不是 0.1.1 发布候选。客户端画面和真人按键没有跑，P0-02 的游戏内渲染验收因此还没完成。

## 已改

| 任务 | 文件 | 改了什么 |
| --- | --- | --- |
| P0-01 | `ModComboStates.java`、`MistletoeCombat.java` | `clickAction` 只做起手音效和少量粒子。伤害、刀光和献祭改到 `TimeLineTickAction` 的第 6 个游戏 tick。同一次施法用 armed 标记，只结算一次。换刀、损坏、封印或死亡时命中帧直接放弃，不会事后补发 |
| P0-02 | `mistletoe.obj`、`tools/gen_assets.py` | 补上 `blade_damaged_luminous`，以及 `item_blade`、`item_damaged`、`item_bladens` 和它们的 `_luminous` 组。物品栏组放在原点附近，配合本体图标的 0.008 缩放 |
| P0-03 | `MistletoeCombatGameTest.java`、`docs/测试与已知限制.md` | 服务端测试覆盖进入状态、命中帧、单次结算和 Super 的先后结果。画面验收写成未执行 |
| P1-02 的可加部分 | `MistletoeTargets.java`、实体类型标签 | 增加空的 `super_sa_include` / `super_sa_exclude`。默认筛选仍是 `Enemy` |
| P1-04 | `MistletoeCombat.applyHalfDurabilityCost` | 扣掉一半耐久后再看刀是否损坏或封印。不允许就发动 |
| P1-05 | `MistletoeDamage.java`、`EntitySlashEffectMixin.java` | 斩击生成时记录来源。伤害钩子只在这把斩击的 tick 里认这个来源，不再只看命中瞬间的主手 |
| P1-07 | `MistletoeFormulasTest.java` | Just 测试用 1.5 倍断言乘法。游戏默认倍率仍是 1.0 |
| P1-08 | GameTest 与测试文档 | 分开写 `./gradlew test` 和 `./gradlew runGameTestServer` |
| P1-09 | `gradle.properties`、`neoforge.mods.toml` | Minecraft 锁在 1.21.1，NeoForge 锁在 21.1 线，Resharped 锁在 `2.1.9-1.21.1` |
| P1-10 | `MistletoeCastGate.java` | 没有上一次施法记录时不进入冷却。0、1、7 tick 的第一次施法可以通过 |
