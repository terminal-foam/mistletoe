# 初雪：玩法功能实现与验收

更新日期：2026-11-09。适用范围：仓库根目录的 Minecraft 1.21.1 / NeoForge 主工程；不代表 `port-1.20.1/` 已同步实现。

依据：用户提供的《槲寄生_初雪_美术资源制作规格书_v1.0.docx》与当前代码。本文把规格中的设计要求、代码实际行为、待实现事项和测试证据分开记录。待办与建议不表示已经修改代码或新增设计决策。

美术资源及接入约定见 [初雪-美术资源交付与接入清单](初雪-美术资源交付与接入清单.md)。

## 1. 设计边界

规格确定初雪为高速输出型武器：较高基础面板、较快攻速，SA 为「霜刃」，向前方扇形区域高速攻击七次。七刀不设末段伤害加成；第七刀可以仅在视觉上收尾。霜刃不新增冰冻、减速、标记、献祭、恢复或额外百分比伤害。

规格没有指定攻击面板、范围、锥角及具体命中 tick；下表中的数值属于当前实现，不能倒推为规格原有要求。

## 3. 与规格的差距及待处理事项

### F-01 七段等伤的验收口径

规格要求“七刀单次伤害完全相同”。当前实现是每段重新读取攻击力，因此中途属性变化会改变输入伤害；目标防御、吸收生命、状态及第三方伤害事件也会影响最终掉血。

建议采用以下验收口径，尚未作为新机制落地：

> 七段使用相同伤害规则，无末段增伤；在施法者攻击属性和目标防御、状态不变时，各段伤害一致。

若要求七段输入数值始终相同，需要在起手时保存本次攻击力。若要求目标实际扣血始终相同，则还涉及防御及外部事件交互，超出纯美术要求，应单独确认。

### F-02 霜刃中断保护不完整

当前 `beginFrostBlade` 检查施法者存活及手持初雪，但没有检查破损/封印。`frostBladeHit` 没有逐段检查存活、破损或封印；首段还会覆盖起手保存的连段 ID。

建议补齐起手与逐段保护，并在中断时清理本次施法状态。不能假设本体能兜住所有调用路径。应验证死亡、换刀、破损、封印、连段切换及再次施法，不应让旧回调继续补伤。

### F-03 目标范围与友方规则需要明确

当前按施法者与目标距离、眼睛连线和视线方向筛选，不检查墙体遮挡，也没有独立队伍、PvP 或宠物过滤。每段重新读取朝向，转身会改变后续攻击区域。

这些是现有行为，规格尚未明确以下选择：

- 转身时攻击区域随朝向移动，还是固定在起手方向。
- 是否允许穿墙命中。
- 是否攻击队友、玩家和宠物。

霜刃没有调用 `PhaseLockResolvers`。未使用绕过无敌的标签，不等于已经为所有 Boss 实现阶段锁血识别。

### F-04 视觉与伤害范围并非同一条管线

伤害由自定义锥形查询结算；刀光由本体斩击实体绘制。代码使用 roll 角变化产生视觉差异，不能据此认定参考图中的空间扇形排列已经实现。专属刀光、粒子及末段视觉强调见配套美术清单。
