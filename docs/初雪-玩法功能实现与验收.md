# 初雪：玩法功能实现与验收

更新日期：2026-11-09。适用范围：仓库根目录的 Minecraft 1.21.1 / NeoForge 主工程；不代表 `port-1.20.1/` 已同步实现。

依据：用户提供的《槲寄生_初雪_美术资源制作规格书_v1.0.docx》与当前代码。本文把规格中的设计要求、代码实际行为、待实现事项和测试证据分开记录。待办与建议不表示已经修改代码或新增设计决策。

美术资源及接入约定见 [初雪-美术资源交付与接入清单](初雪-美术资源交付与接入清单.md)。

## 1. 设计边界

规格确定初雪为高速输出型武器：较高基础面板、较快攻速，SA 为「霜刃」，向前方扇形区域高速攻击七次。七刀不设末段伤害加成；第七刀可以仅在视觉上收尾。霜刃不新增冰冻、减速、标记、献祭、恢复或额外百分比伤害。

规格没有指定攻击面板、范围、锥角及具体命中 tick；下表中的数值属于当前实现，不能倒推为规格原有要求。

## 3. 与规格的差距及待处理事项

### F-01 七段等伤的验收口径

已修复输入侧：`beginFrostBlade` 在起手时把施法者 `ATTACK_DAMAGE` 写入 `FROST_DAMAGE`，七段都读这个快照，不再每段重新读属性。

验收口径仍为：

> 七段使用相同伤害规则，无末段增伤；在目标防御、吸收生命、状态及第三方伤害事件不变时，各段实际掉血一致。

目标防御、吸收、状态及外部伤害事件仍会影响最终掉血；这些属于目标侧和事件侧变量，不改变霜刃七段输入相同这一事实。

### F-02 霜刃中断保护

已修复：

- 起手检查施法者存活、手持初雪、未破损/封印。
- 每段检查存活、手持初雪、未破损/封印。
- 首段不再覆盖起手保存的 `FROST_COMBO`。
- 连段 ID 不匹配、换刀、死亡、破损/封印或快照缺失时调用 `abortFrostBlade`，清空 `FROST_ACTIVE`、连段 ID、伤害快照和 armed 标记。
- 最后一刀结束后也清理本次施法状态。

### F-03 目标范围与友方规则

已明确并实现：

- **每刀跟随当前转身**：每段重新读取 `getLookAngle()`，转身会改变后续攻击区域。
- **允许穿墙**：不做 `hasLineOfSight` 遮挡判定。
- **默认不打玩家、同队目标和有主宠物**：在 `acceptsFrostBlade` 中按所有者 UUID 过滤，主人离线或不在当前世界时宠物仍受保护；普通敌对/中立生物可命中。
- 范围仍是前方 6 格、完整锥角 100° 的三维锥形。

霜刃没有调用 `PhaseLockResolvers`。未使用绕过无敌的标签，不等于已经为所有 Boss 实现阶段锁血识别。

### F-04 视觉与伤害范围并非同一条管线

伤害由自定义锥形查询结算；刀光由本体斩击实体绘制。代码使用 roll 角变化产生视觉差异，不能据此认定参考图中的空间扇形排列已经实现。专属刀光、粒子及末段视觉强调见配套美术清单。
