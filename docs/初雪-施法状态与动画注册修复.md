# 初雪施法状态与动画注册修复

日期：2026-11-10。基于 `b837731`，适用于 1.21.1 主工程。

## 本次修改

- 霜刃使用仅存在于服务端内存的施法状态，绑定武器对象、玩家槽位、连段和起手时间，不再依赖实体 NBT 中残留的 active 标记。
- 命中只接受当前施法的下一段及对应游戏 tick（第 2～8 tick），拒绝提前、重复、乱序及过期回调。错过一段后终止，不积压补伤。
- 实体 tick 主动检查死亡、换刀、破损、封印、连段与起手时间变化；观察到中断后，恢复装备或修复武器不能恢复旧施法。服务器在同一 tick 内未观察到的换出再换回，不宣称已覆盖。
- 地面快速连段按 SlashBlade 版本统一选择倍率：2.1.9 为 2x，2.0.7 等旧版为 1x。双方分别根据实际加载的版本选择；混用不同版本的客户端和服务端不属于已验证组合。
- 动画表注册延后到 load-complete，明确区分 Supplier、旧动画对象与缺失/未知类型。先验证六个条目，再一次性写入共享表。
- 新版动画接口缺失或倍速设置异常时明确报初始化错误，不再无声地按 1x 播放。旧版预期的 1x 模式不依赖 setSpeed。
- 朝露的 Super 注册改为 NONE，输入入口消费并阻止本体 Super，服务端起手与结算也排除朝露。

本次保留原生右键操作、初雪迅冲斩续段、当前模型及 SA 伤害规则，没有恢复自动点击、服务端直伤循环或全局清无敌帧。

## 验证

- 通过 ECJ 3.39.0 + Java 21 + JUnit Console 1.11.4 独立编译运行无 Minecraft 依赖的测试：**21/21 通过**（原有 12 项，加施法窗口 5 项、版本倍率 2 项、动画表格式 2 项）。
- 现有霜刃范围/低头/宠物 GameTest 改为逐服务器 tick 推进 ComboState 时间线。
- 新增 GameTest：七段快照与重复命中、换刀切回、破损后修复、封印后解除、同连段起手时间改变、朝露 Super 禁用。
- 完整 `build test runGameTestServer` 已尝试，但 NeoForge Maven 返回 403，停在 `createMinecraftArtifacts`；完整编译和上述 GameTest **尚未验证通过**。当前环境也缺少完整 Java 21 JDK 的 javac。
- 客户端启动、右键平A/长按 SA、动画倍率及 2.0.7/2.1.9 兼容仍需实测。不要将单元测试通过当作可发布 JAR 的证明。

```bash
bash gradlew downloadSlashBlade build test

bash gradlew runClient
```
